# R3-04 — One-click install: ZIP with a top-level directory (DONE 2026-11-06)

Brief: `REWORK3.md` §R3-04; audit `AUDIT.md` §4 (P1-03) and §3 (R2-06).

## 1. The defect

The REWORK2 delivery zip unpacked FLAT — no top-level directory — so
`README_REWORK2.md` §1's commands failed at the second line:

```bash
unzip demand-radar-rework2-2026-11-05.zip
cd demand-radar-rework2   # no such directory
```

## 2. The fix (option A from the brief)

The REWORK3 delivery zip carries a single top-level directory
`demand-radar-rework3/`; `README_REWORK3.md` §1 is now:

```bash
unzip demand-radar-rework3-2026-11-06.zip
cd demand-radar-rework3
```

No other install step changed. The zip still excludes `.venv/`,
`.venv-real/`, `__pycache__/`, `.pytest_cache/`, `.ruff_cache/`,
`*.egg-info`, and the 20 MB `reports/rework1/review_r02_raw_github.json`
(documented in-package by `reports/rework1/EVIDENCE_ARCHIVE_NOTE.md`).
